# P8 运维、安全与私有化说明

## 运维指标与告警

系统按 `ai`、`ocr`、`rule`、`import` 四类任务记录独立事件，包含排队时间、执行时长、失败、重试、Token 和估算费用。运维看板提供队列长度、平均耗时、失败率、重试率和分类汇总。日志上下文入库前会递归移除 API Key、Token、密码和 Secret。

企业告警覆盖额度接近阈值、Token 异常、队列积压和任务失败率。告警只能由企业管理员确认或关闭，并保留处理人和处理时间。

## 模型健康与降级

已保存的模型配置可以执行主动健康检查。探测只保存状态、耗时、错误码和安全错误信息，不保存密钥或供应商响应正文。

降级顺序为：首选健康配置 → 其他健康配置 → 企业本地模型 → 手工录入。完全离线模式不会选择外部模型；即使本地模型不可用，手工录入仍然可用。

## 图纸和 PQR 数据外发

图纸和 PQR 发送到外部模型前必须展示并确认以下内容：

- 将发送的文档、服务商域名和处理目的；
- 数据可能离开企业网络或所在地区；
- 服务商的数据保留、训练和删除政策由其合同与隐私政策决定；
- 授权绑定文档、服务商域名、隐私说明版本和哈希，可设置到期时间并随时撤销；
- 拒绝授权不会阻止手工录入或企业本地模型流程。

后台异步任务执行前会再次检查授权，已撤销或过期的授权不能继续使用。

## 部署档位

- `saas`：允许平台或授权的外部模型。
- `private`：企业私有部署，可采用域名白名单或企业本地模型/OCR。
- `offline`：完全离线，禁止外部模型和外部存储；使用本地模型、本地 OCR 或手工录入。

服务端环境变量 `DEPLOYMENT_MODE` 设置实例默认档位；企业部署配置用于进一步收紧网络与模型策略。

## 备份与恢复验证

一次通过的验证必须同时满足：

- 数据库备份完整；
- 原始上传文件已备份；
- 字段证据与派生证据已备份；
- 资格规则版本和冻结快照已备份；
- 审批实例、审批历史和批准快照已备份；
- 清单校验和验证通过；
- 已在隔离目标完成恢复演练。

缺少任意一项时只能登记为 `partial` 或 `failed`，不能作为可恢复备份使用。

## 租户导出与删除

企业数据导出和删除使用生命周期任务：申请 → 第二名管理员复核 → dry-run 清单 → 明文确认执行 → 完成审计。申请人不能自行复核。删除申请、批准和最终执行使用三段不同确认文本；删除前必须生成导出清单。数据库删除依赖经过迁移验证的租户外键级联，生命周期审计使用 `SET NULL` 保留。

## 凭据轮换

AI API Key 轮换后密钥版本递增、健康状态重置，并新增不含密钥内容的轮换审计。JWT、数据库、Redis 和对象存储凭据仍按运维手册轮换；轮换记录可以使用同一审计表登记。
