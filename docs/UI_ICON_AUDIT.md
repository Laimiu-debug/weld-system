# 焊序 UI 与图标审查基线

更新时间：2026-08-22

## 目标风格

焊序采用现代工程科技 SaaS 风格：精密网格、深海军蓝、电弧青、清晰的数据层级和克制的动效。避免传统工业拟物、过量玻璃拟态、装饰性渐变和多套图标混用。

参考规范：

- Vercel Geist：高对比色阶、精密网格、紧凑但可读的数据界面
- Microsoft Fluent 2：Regular 用于导航与操作，Filled 只强调选中状态
- Ant Design：通用系统图标保持统一线宽；行业业务图标可以单独设计
- Lucide / Phosphor：24px 网格、清晰轮廓、SVG 和可访问性约束

## 品牌标识

`BrandMark` 由三部分组成：

- 左右白色折角：待焊母材和坡口
- 中央蓝青折线：连续焊缝与“序列”
- 顶部三束青色短线：焊接电弧

标识必须在 16、24、32、40、64px 下保持可辨识。禁止在标识外再叠加玻璃底、盾牌或其他图标。

## 图标层级

### 系统图标

保存、编辑、删除、搜索、返回、刷新、下载等通用动作继续使用同一套 Ant Design Outline 图标。危险操作只通过语义色强调，不更换成夸张图形。

### 行业图标

`ProductIcon` 统一使用 24×24 viewBox、1.75px 圆角线条：

| 模块 | 图形语义 |
| --- | --- |

| PQR | 试验烧瓶与合格标记 |
| pPQR | 预评定手册与新增标记 |
| 焊材 | 成束焊材截面 |
| 焊工 | 焊帽与面罩 |
| 设备 | 焊机与焊枪接口 |

| 质量 | 盾形检查与合格标记 |
| 报表 | 柱线组合图 |
