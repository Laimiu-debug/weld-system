# 智能焊序与企业焊接能力库 TODO

> 目标：在不破坏现有 WPS、PQR、焊工、焊材、生产、质量和审批功能的前提下，增加“智能输入 → 企业能力建库 → 图纸解析 → 工艺匹配 → 焊序编排 → 焊材定额 → 生产下发”的完整闭环。

## 已确定的产品原则

- [x] 手工录入是基础能力，任何核心流程都不得强制依赖大模型。
- [x] AI 是现有 WPS、PQR、焊工等模块的可选输入端，不建立第二套正式业务数据。
- [x] 同时支持平台 AI 额度、用户自带 API Key（BYOK）和纯手工录入。
- [x] AI 只生成可追溯的草稿，不得直接批准或写入正式生产工艺。
- [x] 资格范围、WPS 合规匹配和焊材定额优先由确定性规则裁决。
- [x] 用户自定义模块可参与动态提取，但新字段默认不自动参与资格判断。
- [x] 焊序是版本化的工程设计成果；生产任务是批准后生成的执行对象，两者分离。
- [x] 原始证据、AI 提取结果、规则推导结果和正式业务数据分层保存。
- [x] 所有正式结果必须绑定图纸、WPS/PQR、标准规则和焊序的明确版本。

## 待确认的 MVP 决策

- [x] 选择首个标准体系：NB/T 47014—2023（ASME IX 作为后续独立规则包）。
- [ ] 选择首个产品族：建议典型压力容器（筒体、封头、接管）。
- [ ] 确定首批输入格式：建议优先原生 PDF，扫描 PDF 作为需人工复核的增强能力。
- [ ] 确定首批 AI 服务商及兼容协议；业务代码不得与单一厂商 SDK 强耦合。
- [ ] 定义平台额度单位：建议用户侧使用“AI 点数/解析页数”，后台记录真实 Token、OCR 页数和成本。
- [ ] 确定企业外发策略：允许外部模型、仅企业 Key、仅私有模型或完全禁用 AI。
- [ ] 定义 MVP 成功指标和基线：建库耗时、字段修正率、匹配覆盖率、焊序编制时间。

- [x] 支持文本模型、视觉 OCR、OpenAI Responses 和 OpenAI-compatible Chat 协议。

- [x] 禁止模型直接调用正式创建/更新接口。
- [x] 文档内容和自定义字段说明作为数据处理，防御提示注入。

- [x] 设计超时、重试、幂等和可取消任务。（后台任务使用持久化 Job、协作式取消和新 Job 重试）

### 6. API Key、会员额度与用量账本

- [x] 新建 `ai_provider_configs`，支持个人、企业和平台三种作用域。（平台配置继续由服务端环境托管）

- [x] 支持临时使用且不保存 Key、测试连接、轮换和立即停用。
- [x] 企业管理员可禁止 AI/外部模型/个人 Key，或强制使用企业统一 Key。

- [x] 新建 `ai_usage_ledgers`，记录预占、结算、退款和实际 Token。（实际货币成本待价格表）
- [x] 平台额度失败自动退还；BYOK失败不得静默切换平台额度。
- [x] BYOK 不扣平台模型额度，但仍受页数、并发和任务数限制。
- [x] 在任务提交前显示预计消耗和费用来源。
- [x] 增加用户、企业、日/月、单任务和并发限流。（套餐数据驱动；平台与 BYOK 共用任务/并发边界，平台另受日/月点数限制）
- [x] 日志、异常、Celery 参数和审计记录不得出现完整 Key。（校验错误递归脱敏；后台任务仅传 Job ID；响应仅返回掩码）

### 7. 权限、审批和审计

- [x] 增加 `engineering.*`、`import.*`、`capability.*`、`rules.*` 权限。
- [x] 区分上传、识别、修改、审核、发布、规则管理和 Key 管理权限。（个人空间所有者自管；企业空间按角色动作授权）
- [x] 扩展审批文档类型：导入草稿、规则包、产品版本、焊序版本。
- [x] 审批对象必须绑定明确版本快照，禁止审批过程中静默变化。（稳定对象引用、版本键、快照 SHA256；旧 WPS/PQR/pPQR 审批时复核）
- [x] 复用现有审批流程入口，同时保留字段级修改记录。（正式记录发布为草稿后进入原审批流程）
- [x] 增加敏感文件访问审计和 AI 外发审计。（记录主体、工作区、文档、供应商、阶段和页码，不记录正文、对象 Key 或 API Key）

### P0 验收

- [x] 不配置任何模型或 Key 时，现有手工 WPS/PQR/焊工流程全部可用。（路由与手工导入草稿回归覆盖）
- [x] 新增自定义模块后无需重新训练模型即可生成动态提取 Schema。
- [x] AI 不能绕过现有权限、校验、审批和 Service 层写正式数据。
- [x] 任一发布字段可追溯到文件、页码/区域、识别值和审核记录。
- [x] 平台额度与 BYOK 的用量和费用来源可审计且不会混扣。

- [x] 保留“手工新建”和“从已有记录复制”。（WPS/PQR/焊工均保留手工新建，WPS/PQR 保留复制）
- [x] 三个入口复用同一导入任务和审核工作台。
- [x] 支持用户指定模板，也支持先分类再推荐模板。（解析文本按类型、标准和焊接方法分类；对当前工作区可见模板打分推荐，用户仍可改选模板或模块）

### 2. PQR 导入

- [x] 支持单个和批量 PQR PDF 上传。
- [x] 提取编号、标准版本、母材、厚度、接头、方法、焊材和参数。
- [x] 提取 NDE、拉伸、弯曲、冲击、硬度等试验事实。

### 3. WPS 导入

- [x] 支持多方法、多焊层和重复参数表格。（内置 WPS 提取 Schema 增加方法顺序、焊层/焊道和重复参数表三类结构化表格）

- [x] 使用现有 WPS 模块表单完成校核和发布。（导入草稿进入原动态表单，校核后经现有 WPS Service 保存草稿）

### 4. 焊工与资质导入

  - [x] 支持证书 PDF/图片和结构化 Excel 名册。（Excel 按工作表保留行列边界，图片/扫描 PDF 沿用 OCR 适配层）
  - [x] 提取姓名、编号、证书号、方法、位置、材料组、厚度/直径和有效期。
  - [x] 支持一张证书包含多个持证项目。（合格范围保留在证书 JSON，每项同步建立独立持证项目）
  - [x] 按人员编号、证件信息和人工确认处理同名问题。（仅姓名匹配不自动合并）
  - [x] 检测重复证书、续证、过期和即将到期状态。（30 天内为即将到期）
  - [x] 发布到现有焊工及持证项目模型。（统一调用 WelderService，不建第二套正式数据）

### 5. 审核工作台

  - [x] 左侧显示原文/PDF，右侧复用现有模块化表单。（PDF/图片私有按页预览，DOCX/XLSX 降级为分页原文；右侧按 Schema 模块分组）
  - [x] 字段使用高/中/低置信度和冲突状态标识。（冲突状态包括未确认、未映射、重复、关联值冲突、范围/选项违反）
  - [x] 点击字段可定位原始页码和区域。（私有页面渲染 + bbox 高亮 + 证据原文）

  - [x] 模板外识别内容进入“未映射字段”。（独立发现阶段不重复已映射字段，仍强制页码与证据校验）
  - [x] 允许将未映射字段绑定到已有字段或创建企业自定义字段。（创建的字段写入现有 CustomModule，不只存在于导入草稿）
  - [x] 修改影响关联字段时重新运行局部校验，不重复解析整个文件。（只读取当前草稿/Schema 检查，不调用 OCR/模型，不产生额外费用）
  - [x] 发布前显示必填项、重复项、规则冲突和未确认项清单。（同时检查正式库重复编号）

### 6. 异步任务与批量处理

- [x] 使用 Celery 执行解析、OCR和模型调用。（上传后分页解析进入独立 Celery 任务；OCR 与分阶段模型调用继续在提取任务中执行，队列载荷只含任务 ID）
- [x] 支持排队、处理中、待审核、可发布、部分成功、失败和取消状态。
- [x] 显示文件级和字段级进度。（持久化任务阶段、页面完成数和 Schema 字段处理数；工作台与文件列表均可查看）
- [x] 单文件失败不阻断整个批次。
- [x] 支持失败重试且不重复扣费、不重复发布。
- [x] 支持断点续审和批量发布。

### P1 验收

- [x] 用户可以使用平台额度或自己的 Key 导入同一份文件。

## P2：企业焊接能力库

### 1. WPS/PQR 正式关系

- [x] 增加 WPS 与支持 PQR 的多对多关系，停止依赖单个字符串编号作为唯一关系。（新建 `wps_pqr_support_links`）
- [x] 关系记录支持的焊接方法、范围、来源和人工确认状态。（导入匹配仅生成待确认关系）
- [x] 保存对 WPS/PQR 精确版本的引用。（版本键、快照和 SHA-256 哈希同时冻结）
- [x] 兼容并迁移现有 `wps_number` 数据。（同工作区编号匹配迁移为待确认关系）

### 2. 标准规则包

- [x] 建立 `qualification_rule_packs` 和版本状态：草稿、审核中、已发布、停用。（状态转换不可跳级）
- [x] 建立规则输入、输出、适用标准和条款依据模型。
- [x] 首期只实现已选定的一套标准。（仅启用 NB/T 47014—2023；ASME IX 待后续新规则包）
- [x] 建立规则测试用例，覆盖边界、组合工艺和信息缺失。
- [x] 规则升级不得覆盖历史结果，支持显式重新计算。（新结果指向被取代结果）
- [x] 标准原文授权和引用方式通过合规审查。（只保存标准编号与定位信息，不入库或复制标准原文；发布前有合规元数据门禁）

### 3. PQR 资格推导

- [x] 根据事实字段计算厚度、直径、位置、材料组、方法和附加要求范围。（未经授权规则表验证的扩展维度采用保守精确范围并要求复核）
- [x] 保存规则包版本、输入快照、结果、依据和计算时间。
- [x] 输出符合、不符合、边界条件和需人工确认。
- [x] 缺少关键变量时不得猜测范围。（返回 `insufficient_data` 且范围为空）

### 4. 能力聚合

- [x] 只聚合已批准、未停用且有有效支持关系的 WPS/PQR。（同时校验快照、当前明确合格结果和人工确认状态）
- [x] 聚合材料组、厚度、直径、方法、位置、PWHT、冲击等能力维度。
- [x] 关联当前有效焊工资质、焊材和可用设备。（焊工按证书范围和到期日，焊材按规格/分类和库存，设备按状态和校准日期）
- [x] 显示资料缺失、重复、冲突和无有效 PQR 支持的 WPS。
- [x] 支持按企业/工厂范围查询能力。（沿用工作区数据权限并支持工厂筛选）
- [x] 能力记录可回溯到正式 WPS/PQR 和原始文档。（显示精确版本、资格计算、规则依据与导入文档 SHA-256）

### 5. 能力库 UI
